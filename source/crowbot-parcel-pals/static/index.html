Transfer notes & diagnostics
Uploads replace the current Crowbot callback and workspace. ACK confirms transfer/reload, not physical execution. Canceling upload disconnects the shared device and can leave partial data. Readback is not an exclusive transaction. The browser cannot guarantee interrupting a device-side wait; use the physical power switch if necessary. Closing this window does not disconnect shared BLE.
