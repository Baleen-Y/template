How the blocks link to the game

Event blocks run when the matching game event happens. Actions under that event run from top to bottom.

Send BLE command writes the exact text in the block through the current iCreator shared BLE connection. Failed commands are not silently replayed.

Game physics blocks change the browser game only. They do not claim to change device firmware.
